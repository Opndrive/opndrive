Move the spreadsheet preview to xlsx 0.20.3

The spreadsheet preview parsed files with `xlsx` 0.18.5, which has a prototype
pollution bug (CVE-2023-30533) and a regular expression denial of service
(CVE-2024-22363). Both are fixed in 0.20.3, but SheetJS stopped publishing to
npm after 0.18.5, so the fixed release comes from their own CDN, which is the
install SheetJS documents. The URL names the exact version.

Dependabot cannot see a CDN dependency, so this one has to be bumped by hand.
